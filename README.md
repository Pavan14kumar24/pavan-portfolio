# Pavan Portfolio Website

A responsive, interactive one-page portfolio created for job opportunities.

## Run locally

Open `index.html` directly, or use VS Code Live Server.

## Replace before publishing

Search the project for these placeholders:

- `www.linkedin.com/in/pavankumarmagubehara241214`
- `YOUR-GITHUB`
- `magubeharapavankumar.com`
- `assets/Pavan-Kumar-Magubehara-Resume.pdf`
- The placeholder previous-employment timeline entry

Add your résumé PDF inside the `assets` folder using the filename above, or update the link in `index.html`.

## Publish

Good free options:

1. GitHub Pages
2. Cloudflare Pages
3. Netlify
4. Render Static Site

## Main files

- `index.html`: portfolio content and structure
- `styles.css`: layout, animations, responsive design
- `script.js`: navigation, scroll reveals, counters, cursor glow, and tilt interaction
